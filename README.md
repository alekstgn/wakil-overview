## Проблема

Владелец малого бизнеса в Эмиратах тратит десятки часов и тысячи дирхамов на консультантов, чтобы не пропустить:

- продление торговой лицензии (DED) или фриланс-разрешения;
- визы сотрудников (GDRFA/ICP);
- обязательную медстраховку (DHA);
- налоговые дедлайны — VAT и корпоративный налог (FTA);
- зарплатные реестры (MOHRE/WPS), Ejari.

Просрочка = штрафы в тысячи AED, блокировки и визовые риски. Консультант берёт 2 000–5 000 AED за запрос.

## Решение

Wakil — проактивный ИИ-агент «один на компанию»:

1. **Паспорт компании** — при онбординге собирает тип лицензии, эмират, activity codes, даты, сотрудников.
2. **Календарь обязательств** — сам строит граф дедлайнов с порогами напоминаний (30/14/7/2 дня).
3. **Ответы с цитатами** — на вопросы по регуляторике отвечает только по официальным источникам (ded.gov.ae, icp.gov.ae, tax.gov.ae, mohre.gov.ae) с указанием первоисточника.
4. **План продления** — по шагам: документы, стоимость в AED, портал; готовит черновики документов (DOCX).
5. **Human-in-the-loop** — каждый значимый шаг подтверждает владелец; все действия агента пишутся в audit log.
6. **Напоминания** — Telegram (далее — WhatsApp).

## Агентность (почему это агент, а не чат-бот)

Многошаговое планирование → вызов инструментов (RAG по официальным источникам, календарный движок, генерация документов) → действие с подтверждением человека → память диалога (thread_id для чекпоинтера). Полный журнал рассуждений и действий сохраняется.

## Статус (прототип, октябрь 2026)

- **Telegram-бот работает вживую** (см. «Живое демо» выше): онбординг, привязка компании, вопросы-ответы с цитатами, `/plan`, напоминания, автоопределение языка.

- FastAPI-бэкенд: компании, сотрудники, обязательства, события, планы, шаги планов, KB, напоминания, audit log — REST API.
- Supabase (Postgres): 11 таблиц, RLS включён на всех, доступ только сервисным ключом с бэкенда.
- Движок дедлайнов: генерация compliance-событий из правил каталога.
- RAG-пайплайн: автозагрузка стартовых официальных источников, чанкинг, цитирование.
- Тесты: pytest (API, модели, календарный движок, RAG-пайплайн).

*English summary:* **Wakil** is a proactive AI compliance agent for UAE small businesses: it builds the company's obligation calendar, answers regulatory questions with citations from official government sources only, drafts renewal documents, plans every renewal step (documents, AED cost, portal) with human-in-the-loop confirmation, and sends reminders via Telegram. **Live demo bot: [t.me/wakil_compliance_bot](https://t.me/wakil_compliance_bot).** Prototype (FastAPI + Telegram bot + Supabase) is working; code in a private repository, access by invitation.
